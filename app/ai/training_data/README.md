# Ciguli Training Data

Put Ciguli's training and reference notes here.

Recommended files:

- `aviation_notes_tr.md` for Turkish aviation explanations
- `aviation_notes_en.md` for English aviation explanations
- `conversation_examples.md` for example user/assistant conversations
- `chart_reading_rules.md` for approach chart reading rules

This folder is not a real model fine-tuning system yet. It is the knowledge base
folder that will later feed the local/private AI model or retrieval system.
